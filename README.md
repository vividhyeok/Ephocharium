# Epocharium

작은 세계, 끝없는 역사. **0.4.0** 한국어 자율 문명 관찰형 픽셀 샌드박스입니다. 문명은 스스로 성장·교류·경쟁하며 플레이어는 관찰하다가 필요한 순간에만 개입합니다.

## 실행

Node.js 24에서 검증했습니다. 외부 AI API·API 키·별도 게임 서버 없이 실행됩니다.

```sh
npm ci
npm run dev
```

브라우저에서 Vite가 출력한 주소를 여세요. `npm run build` 결과는 `dist/`입니다.

## 달라진 문명과 시간

- 원시 부족 → 초기 농경 → 고대 도시 → 고대 왕국 → 고전 → 중세 → 근세 → 산업 → 전기 → 현대 → 정보 → 자동화 → 우주 → 행성간의 **14단계**입니다. 단계마다 픽셀 건축, 식량 생산, 경제, 주거 수용량과 이동 속도가 달라집니다.
- 후기에는 전력·산업 시설·통신망·자동화 생산·위성·탐사 사업이 자원 소비와 실제 생산·연구·교역 수입에 연결됩니다. 최종 시대 이후에도 기술과 도시 개발이 증가할 수 있습니다.
- 연구는 인구·재산·자원·안정성·교류와 발전 성향에 영향을 받으며 고도 기술일수록 느려집니다. 진입에 필요한 인구·안정·재산·전력이 부족하면 정체되고, 기근·불안·전쟁은 쇠퇴를 일으킬 수 있습니다. 특정 연도에 시대를 강제하지 않습니다.
- 1·2·5·10·20배속은 유지합니다. **1배속은 4초에 1년, 20배속은 초당 5년**입니다. 연간 인구·생산·연구·주민 이동·군대·항공 계산 전체를 같은 순서로 실행합니다. 연도 숫자만 늦춘 방식이 아닙니다. 같은 시드와 개입 시점에서 같은 연도까지 계산하면 배속과 관계없이 결과가 같습니다.

세 시드에서 각각 18,000년까지 실행했습니다. 1,000년에는 고전·중세, 5,000년에는 산업·전기, 18,000년에는 전기·현대·정보 수준의 문명이 함께 존재했습니다. 발전 조건과 실제 측정·한계는 [개발 현황](docs/STATUS.md), 전체 측정값은 [벤치마크](docs/benchmark-0.4.json)에 있습니다.

## 관찰하기

1. 왕국을 선택하고 **도시 가까이 보기**를 누르세요. 대표 주민 집단은 집·직업·목적지·경로·작업 상태와 실제 좌표를 갖습니다. 농부의 낫, 벌목꾼의 도끼, 광부의 곡괭이와 시대별 군대 장비를 확대해 볼 수 있습니다.
2. 국가 패널에서 시대, 발전 정체 이유, 현재 강점 두 가지와 정치 체제를 읽습니다. **기반 시설과 연구 자산**을 펼치면 전력·산업·통신망·위성·탐사 현황을 볼 수 있습니다.
3. 위쪽 전쟁·동맹 표시에 마우스를 올리거나 키보드 초점을 옮기면 상대국·시점·이유가 나옵니다. 누르면 조약별 맥락과 외교 연표가 열립니다. 전선 가까이 보기로 행군·공성·점령을 관찰합니다.
4. **역사**에서 사건 표시량과 자동 카메라를 조절합니다. 자동 이동은 관찰 모드의 주요 사건에만 반응하고 최소 12초 간격을 둡니다. 작은 사건 알림을 누르면 위치로 이동합니다.
5. 역사에서 시대별 관측 요약과 200년 단위 요약, 최대 영토와 전성기, 국가별 시대 이행, 오래된 국가·새 국가와 최근 영토 변화를 읽습니다. **과거와 현재의 영토 비교**는 최근 8회, 100년 간격의 지도에서 바뀐 영토를 밝게 표시합니다.

빠르게 후기 도시를 보고 싶다면 `새 세계 → 관찰 모드`를 선택하세요. 이 프리셋은 발전한 기술과 도시를 초기 조건으로 제공하며 일반 세계의 발전을 강제하지 않습니다.

## 개입과 지도

- 문명 도구에서 전쟁·동맹·평화를 고른 뒤, **대상·상대 국가를 지도나 목록에서 지정**하고 적용합니다. 같은 패널에서 실행할 개입을 바꿀 수 있습니다. 접경이 없는 전쟁에는 지상 전선이 없다고 안내합니다. 가까운 국가를 자동 선택하는 빠른 개입도 남겨 두었습니다.
- 지형·재해 브러시는 적용될 타일 범위를 사용 전에 표시합니다. **↶ 취소**로 직전 개입 한 번을 되돌립니다. 드래그 한 번이 한 작업이며, 개입 직전의 세계 전체를 복원하므로 그 뒤 진행된 시간도 되돌아갑니다.
- 설원은 북부·고지대의 불규칙한 눈밭으로 유지합니다. 새 지도는 네 면이 바다이며 최대 크기는 256×166입니다. 이전 지도는 가장자리를 지우지 않고 바다를 덧붙이고 정착지·이동 경로·역사 위치를 함께 옮깁니다.
- 국경·영토 색과 국가 표지의 전쟁·동맹 기호로 상태를 구분합니다. 이름에 임의의 ‘2세’를 붙이지 않으며 실제 독립에는 출신 국가를 표시합니다.

## 조작과 저장

- 관찰 도구의 좌클릭 드래그 또는 우클릭 드래그로 이동하고 휠로 확대합니다. 능력은 좌클릭·드래그로 사용합니다. 두 국가 지정은 클릭당 한 국가를 선택합니다.
- 스페이스: 재생/일시정지, 숫자 1–5: 배속, ESC: 패널 닫기·관찰 도구로 복귀.
- 미니맵·왕국 목록과 줌 버튼으로 위치를 이동합니다.
- 15초 자동 저장, 수동 슬롯 3개와 JSON 세계 파일 입출력을 지원합니다. 브라우저 데이터를 삭제하기 전 파일로 보관하세요.
- 구버전 기술은 새 척도로 한 번만 이전합니다. 기존 항공 문명은 정보 수준에서 이어지고, 연도·인구·난수 상태·역사 날짜는 유지됩니다. 새로운 규칙을 적용한 이후의 미래는 이전 버전과 달라집니다.

## 검증과 구조

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
node scripts/observe-bench.mjs
```

엔진은 `src/engine.ts`, 시대와 발전은 `src/eras.ts`·`src/progression.ts`, 주민·도시·군대·항공은 `src/civilization.ts`, 외교는 `src/diplomacy.ts`, 고정 시계는 `src/time.ts`·`src/worker.ts`, 기록은 `src/history.ts`에서 처리합니다. Canvas 렌더링은 `src/MapView.tsx`·`src/scene.ts`입니다.

인구는 집계 모델이며 표시 주민은 대표 집단입니다. 전원 개별 생애 AI, 개별 무기 재고·탄도, 해전·공중전은 없습니다. 위성·탐사는 자원과 연구·수입에 영향을 주는 집계 사업이며 별도의 우주 지도나 궤도 물리·행성 식민지 시뮬레이션은 없습니다. 전체 명세의 최종 완성판은 아닙니다.

[GitHub 저장소](https://github.com/vividhyeok/Ephocharium). GitHub Actions에서 엔진·빌드·브라우저 검증을 실행합니다. Vercel 설정은 준비되어 있으나 팀 접근 오류로 원격 배포는 미완료입니다.
