# Epocharium 0.6.0 — 에피와 함께 관찰하는 문명

작은 세계, 끝없는 역사. React/Vite/TypeScript와 Worker 기반 자율 문명 관찰 게임입니다. 국가를 직접 경영하는 대신 세계를 지켜보고 필요할 때 개입합니다. [0.6.0 변경·검증·한계](docs/RELEASE-0.6.md)

## 게임 실행

Node.js 24에서 실행합니다. 게임과 에피의 자동 사건 보고는 API 키 없이 동작합니다.

```sh
npm ci
npm run dev
```

Vite가 출력한 주소를 엽니다. `npm run build` 결과는 `dist/`입니다. 기존 0.5 저장을 불러올 수 있습니다. 새 규칙 적용 이후의 미래는 이전 버전과 달라집니다.

## 서기관 에피

상단 **에피**를 열어 세계를 질문하세요. 선택 국가에 대해 묻기, 답변의 국가 링크로 지도 보기, 스트리밍·중단·재요청을 지원합니다. 관측 연도를 답변마다 표시하며, 질문 뒤 시간이 진행돼도 그 시점 자료를 사용합니다. 대화는 세계별 브라우저 로컬 저장입니다.

- 인구·경제·군사·기술·영토·직접 동맹 순위와 결정론적 종합 순위
- 국가 비교, 지도자 개인 성향과 국가 정책의 구분
- 전쟁·평화 기간, 최근 사건, 성장·쇠퇴와 발전 정체 이유
- 50년 간격으로 보존한 과거 세력 집계 비교. 기록이 없는 과거는 정보 부족으로 표시
- 첫 산업화·해외 개척·큰 국가의 멸망·인구 급감·오랜 평화 등은 무료 로컬 보고. 최소 60초 간격, 중복 억제, 표시 설정에서 끄기

### 대화 연결: 서버 환경변수 3개

1. `.env.example`을 `.env.local`로 복사합니다.
2. `DEEPSEEK_API_KEY`에 DeepSeek API 키를 등록합니다.
3. `EPI_ACCESS_TOKEN`에 24자 이상의 무작위 초대 코드를 등록하고 `EPI_ENABLED=true`로 설정합니다.
4. 두 터미널에서 각각 실행합니다.

```sh
npm run dev:epi
npm run dev
```

로컬 API는 127.0.0.1:5174, 브라우저는 Vite의 `/api/epi` 프록시를 사용합니다. 서버 코드나 환경변수를 바꾸면 `dev:epi`를 다시 실행하세요. 에피의 **대화 접근 설정 → 초대 코드**에 `EPI_ACCESS_TOKEN` 값을 입력합니다. API 키를 이 입력란에 넣지 마세요.

초대 코드 생성 예시:

```sh
node -e "console.log(require('node:crypto').randomBytes(24).toString('hex'))"
```

키가 없거나 활성화되지 않은 경우 게임은 계속 실행되고 에피는 안내 상태를 보여줍니다. 기본 제공자는 DeepSeek, 모델은 `deepseek-flash`, 주소는 `https://api.deepseek.com`, thinking은 disabled입니다. React 번들에는 공급자 키가 포함되지 않습니다.

### 접근과 사용량 보호

AI는 기본 비활성화입니다. 활성화 후에는 서버가 초대 코드의 해시를 일정 시간 비교하고, 동일 출처·요청 스키마·96KB 본문·질문 길이를 검사합니다. 프로세스당 동시 2개, 시간당 12개, 일당 60개의 제한과 10분 중복 요청 ID 차단을 적용합니다. 한 질문은 최대 2회 공급자 호출, 회당 최대 출력 1,100토큰, 총 출력 6,000자, 45초 타임아웃입니다. 불확실한 청구의 중복을 피하도록 자동 재호출은 하지 않습니다. 사용자의 다시 요청은 새 호출입니다.

**서버리스 인스턴스의 메모리 제한은 전 배포의 총과금 한도가 아닙니다.** 불특정 다수에게 코드를 배포하거나 코드가 유출된 상태로 활성화하지 마세요. 공개 AI 운영은 별도의 전역 인증/속도 제한과 공급자 계정의 지출 제한을 준비한 뒤 진행해야 합니다. 준비 전에는 `EPI_ENABLED=false`로 유지합니다. DB나 유료 인프라는 필수로 추가하지 않습니다.

## 관찰과 개입

- 14개 문명 단계, 1·2·5·10·20배속, 고정 연간 계산, 대표 주민 집단·작업·행군·공성·교역을 유지합니다. 1배속 4초/년, 20배속 5년/초입니다.
- 지도 표시에서 국가명·도시명·외교 연결·에피 보고를 개별 설정합니다. 국가 호버/선택 시 실제 양자 동맹은 청록색, 전쟁은 주홍색 점선입니다.
- 국가 목록에서 인구·문명·영토 순위, 동맹망·대표 종교 그룹, 이름 검색을 사용합니다. 동맹망은 간접 연결을 포함하고 직접 동맹은 지도 연결선으로 확인합니다.
- 국가 패널은 시대·실제 자원·도시·발전 정체 원인·지도자 성향을 보여줍니다. 가동 인력이 줄면 도시의 시설과 건물 밀도도 줄며, 폐허와 회복을 구별합니다.
- 지형은 수문·설원·산맥·유한 광상과 연결됩니다. 간척·관개는 자원과 공사 기간을 요구하고, 해외 개척은 이주민이 배로 도착한 뒤 정착합니다.
- 전쟁·동맹·평화는 대상 두 국가를 지정해서 개입합니다. 지형·재해 브러시, 직전 개입 취소, 사건 기록과 지도 이동을 유지합니다.
- 드래그 이동, 휠/핀치 확대, 스페이스 재생/정지, 숫자 1–5 배속, ESC 닫기를 지원합니다. 채팅 입력 중 게임 단축키는 실행되지 않습니다.
- 자동 저장 15초, 수동 슬롯 3개, JSON 내보내기·불러오기. 브라우저 데이터를 지우기 전에 세계를 파일로 보관하세요.

```sh

```

장기 측정은 [0.6 원본](docs/benchmark-0.6.json)과 [0.5 기준선](docs/benchmark-0.5.json)으로 보존합니다. 측정과 제한은 릴리스 노트에 기록합니다. 실제 DeepSeek 연동은 [수동 검증](docs/EPI-MANUAL.md)을 따르세요. 자동 테스트는 모의 공급자를 사용하며 유료 API를 호출하지 않습니다.

## Vercel 배포

기존 `ephocharium` Vite 프로젝트를 사용합니다. Next.js로 전환하지 않습니다. `api/epi.ts`가 Node.js Function이며, 중단 전달과 60초 실행 제한을 `vercel.json`에 설정했습니다. Git 연결 브랜치를 push하면 기존 프로젝트에서 빌드합니다. 대화가 필요할 때만 프로젝트 Settings → Environment Variables에 위 3개 변수를 등록한 뒤 재배포하고, 같은 초대 코드를 에피 패널에 입력하세요. 키 등록 전에는 게임과 로컬 사건 보고만 동작합니다.

## 구조와 한계

- `src/engine.ts`, `living.ts`, `demographics.ts`: 결정론적 세계·생산·인구
- `src/archives.ts`: 지도자 개인 성향, 영구 누적 통계, 제한된 세부 기록과 과거 집계
- `src/epi/analysis.ts`: 읽기 전용 질문별 관측 자료 추출
- `src/epi/protocol.ts`, `server/epi.ts`, `api/epi.ts`: 스키마 검증, 허용된 질의 도구, DeepSeek 스트리밍, 접근 보호
- `src/epi/EpiPanel.tsx`, `reports.ts`: 세계별 대화와 무료 로컬 보고
- `src/scene.ts`, `MapView.tsx`: 도시 발전·쇠퇴와 지도 렌더링

종합 세력은 상대 로그 인구 25%·재산 15%·군사 20%·기술 20%·영토 10%·직접 동맹 10%입니다. 전투 승률 예측이 아닙니다. 군사 부문은 실제 배치된 부대 전력으로 평가합니다. 지도자 세부 기록은 최근 80대, 시대별 누적 횟수와 지도자·전쟁 총횟수는 유지됩니다. 세력 집계는 50년 간격 최근 400회입니다. 에피는 가장 최근 8턴과 이전 질문 요약을 전송하고, 로컬 세부 대화는 최근 20턴을 보존합니다.

인구는 3개 코호트와 집계 경제 모델입니다. 전원 개별 생애, 개별 무기 재고·탄도, 상세 해전·공중전, 우주 궤도 물리는 없습니다. LLM 해석에는 오답 가능성이 있으며 관측 수치·사건과 구분해서 읽어야 합니다. 외부 서비스의 실제 응답과 지연은 모킹 테스트로 보장하지 않습니다.
