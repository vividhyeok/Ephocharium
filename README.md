# Epocharium

작은 세계, 끝없는 역사. 한국어 자율 문명 관찰형 웹 샌드박스입니다. 현재 버전은 **0.3.0**이며 전체 최초 명세의 최종 완성판은 아닙니다. 구현 범위와 검증·한계는 [개발 현황](docs/STATUS.md)에 기록했습니다.

## 실행

Node.js 24에서 검증했습니다. AI API, API 키, 별도 게임 서버가 필요하지 않습니다.

```sh
npm ci
npm run dev
```

브라우저에서 Vite가 출력한 주소를 여세요. 배포 빌드는 `npm run build`이며 `dist/`가 생성됩니다.

## 지도와 외교 관찰

설원은 북쪽·고지대의 불규칙한 눈밭으로 남고, 새 지도는 네 면을 바다가 둘러쌉니다. 크기는 최대 256×166입니다. 이전 저장은 가장자리를 지우지 않고 바다를 덧붙이며 좌표·이동 경로·역사 위치를 옮깁니다.

화면 상단의 **전쟁 / 동맹** 표시는 마우스를 올리거나 키보드로 초점을 옮기면 상대국·시점·이유를 보여 줍니다. 누르면 역사 안의 **외교 관측실**에서 조약과 연표를 읽습니다. 동맹은 자원·기술 교류와 실제 접경을 가진 동맹국의 방어 참전에 영향을 줍니다. 문명 도구에서 동맹을 직접 중재할 수도 있습니다.

국경은 색과 이중 윤곽으로 구분하며, 도시를 확대하면 상세 픽셀 주민의 낫·도끼·곡괭이·망치와 시대별 군대의 창·검·총을 볼 수 있습니다. 국가 이름에 임의의 ‘2세’를 붙이지 않으며 실제 독립한 국가는 국가 정보에서 출신 국가를 표시합니다.

## 살아 움직이는 문명 보기

1. 왕국을 선택하고 **도시 가까이 보기**를 누르세요. 농부·광부·벌목꾼·건축가·상인·지도자가 실제 저장된 경로를 따라 이동합니다.
2. 시간이 흐르면 인구와 정착지가 늘고 자원을 채취합니다. 화면의 주민은 대표 집단이며 인구와 표시 비율은 왼쪽에 나옵니다.
3. 기술·경제·자원 상태에 따라 부족 → 농경 → 왕국 → 산업 → 현대 → 항공 시대로 발전합니다. 건물·도로·차량이 달라지고, 항공 기술과 공항 두 곳을 갖추면 실제 항공 교역이 시작됩니다.
4. 전쟁이 생기면 국가 정보의 **전선 가까이 보기**로 군대의 행군·전투·점령을 관찰하세요. 문명 도구로 전쟁·평화를 유도할 수 있습니다.
5. 지형에 커서를 올리면 목재·광물과 해당 주민의 직업을 확인할 수 있습니다. 왕국 패널에는 정치 체제와 지도자의 권위도 표시됩니다.

빠르게 발전한 세계를 보려면 `새 세계 → 관찰 모드`를 선택하세요. 이미 발전한 국가를 초기 조건으로 제공하지만 특정 연도에 발전·전쟁을 강제하지 않습니다. 전쟁은 국경·관계·성향 등 조건에 따라 발생하므로 모든 시드가 같은 결과를 내지는 않습니다.

## 조작과 저장

- 관찰 도구에서 좌클릭 드래그, 다른 도구에서 우클릭 드래그로 지도 이동. 휠로 확대/축소.
- 좌클릭/드래그: 선택한 능력 사용. 우클릭: 국가 정보.
- 스페이스: 재생/일시정지. 숫자 1–5: 1·2·5·10·20배속. ESC: 패널 닫기 및 관찰 도구 선택.
- 미니맵·왕국 목록으로 위치 이동, `＋`, `−`, `전체 보기`로 카메라 조절.
- 인간 도구는 20명이 정착을 시작합니다. 인구 지원은 100명을 더합니다. 식량·주거·자원이 부족하면 위기가 생길 수 있습니다.
- 15초 자동 저장, 수동 슬롯 3개, 삭제·불러오기, JSON 파일 내보내기·가져오기. 브라우저 데이터 삭제 전에는 파일로 보관하세요.
- 기존 0.1 저장도 불러올 수 있습니다. 기존 인구·지형·역사·난수 상태를 유지하면서 새로운 주민·자원 상태를 추가합니다.

## 구조와 검증

| 파일                              | 역할                                                       |
| --------------------------------- | ---------------------------------------------------------- |
| `src/engine.ts`                   | 결정론적 지형·인구·경제·외교·역사와 능력                   |
| `src/civilization.ts`             | 주민 경로·직업·채취, 정착지·주거·기술·권력, 군대·항공 교역 |
| `src/worker.ts`                   | 고정 시간 단위 시뮬레이션과 명령 처리                      |
| `src/MapView.tsx`, `src/scene.ts` | 지형 캐시·카메라·시대별 건물·실제 이동 상태 렌더링         |
| `src/main.tsx`                    | 한국어 UI·생성·관찰·정보·저장 흐름                         |
| `src/storage.ts`, `src/store.ts`  | IndexedDB 및 Zustand UI 상태                               |

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

엔진 19개와 브라우저 8개 검증을 제공합니다. 인구 전체는 집계하며, 화면의 모든 표시 주민 집단은 경로·작업·좌표를 저장합니다. 일반 시민 전원의 생애·가족·개별 AI를 구현한 것은 아닙니다. 도시별 독립 경제, 여러 갈래 연구 트리, 해전·공중전 등도 후속 작업입니다.

PixiJS 대신 Canvas 2D를 사용하며 지형·구조물은 스냅샷이 바뀔 때 캐시로 갱신합니다. 주민·부대·항공기는 실제 시뮬레이션 상태 사이를 보간합니다. 외부 폰트·AI·게임 서버에 의존하지 않습니다. 오프라인 재접속을 위한 서비스 워커는 아직 없습니다.
