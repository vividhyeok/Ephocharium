# Epocharium

작은 세계, 끝없는 역사. 한국어로 플레이하는 자율 문명 관찰형 웹 샌드박스입니다.

**현재 버전은 플레이 가능한 첫 번째 개발 단계(0.1)입니다. 첨부된 전체 게임 명세의 최종 완성판은 아닙니다.** 구현 범위와 남은 과제는 [개발 현황](docs/STATUS.md)에 구분했습니다.

## 실행

Node.js 24에서 검증했습니다. AI API, API 키, 별도 게임 서버가 필요하지 않습니다.

```sh
npm ci
npm run dev
```

브라우저에서 Vite가 출력한 주소를 여세요. 배포 빌드는 `npm run build`이며 `dist/`가 생성됩니다.

## 플레이

- 첫 화면에는 네 왕국이 있습니다. `새 세계`에서 빈 세계, 문명의 시작, 네 왕국, 군도 세계, 전쟁의 시대, 관찰 모드를 선택할 수 있습니다.
- `생명 → 인간`을 고른 후 땅을 누르면 20명이 정착을 시작합니다. 몇 년 후 나라가 생깁니다.
- `관찰` 도구에서 좌클릭 드래그, 다른 도구에서 우클릭 드래그로 지도를 움직입니다. 휠로 확대/축소합니다.
- 좌클릭 또는 드래그로 능력을 적용합니다. 우클릭으로 국가 정보를 확인합니다.
- 스페이스: 재생/일시정지. 숫자 1–5: 1·2·5·10·20배속. ESC: 패널 닫기 및 관찰 도구 선택.
- 인구 지원은 인구와 잠재 노동력을 늘립니다. 식량·영토가 부족하면 인구가 줄어들 수 있습니다.
- 관찰 모드는 도구를 감추며, 선택적으로 사건 위치를 따라갑니다.
- 오른쪽 왕국 목록을 누르면 수도와 국가 정보를 함께 볼 수 있습니다. 미니맵으로 원하는 지역을 찾고 `＋`, `−`, `전체 보기` 버튼으로 지도를 조절할 수 있습니다.
- 자동 저장은 15초 주기입니다. 저장 패널에 수동 슬롯 3개, 불러오기, 삭제, JSON 파일 입출력이 있습니다. 브라우저 저장 공간을 지우면 로컬 저장도 사라지므로 파일로 보관할 수 있습니다.

## 검증

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Vitest는 명세 A–H를 포함한 엔진 테스트를, Playwright는 브라우저의 실제 지도·저장·조작 흐름을 검증합니다. 상세 결과와 측정 조건은 [검증 기록](docs/STATUS.md)을 참조하세요.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/engine.ts` | 결정론적 난수, 지형, 식량·경제·인구·기술, 외교·전쟁·분열, 신의 능력 |
| `src/worker.ts` | 고정 시간 단위 시뮬레이션과 UI 명령 처리 |
| `src/MapView.tsx` | 픽셀 지도, 지형 캐시, 확대·이동, 주민·재해 애니메이션 |
| `src/main.tsx` | 한국어 UI, 세계 생성, 역사·국가 패널, 저장 흐름 |
| `src/storage.ts` | IndexedDB 저장·복원 |
| `src/store.ts` | Zustand UI 상태 |

일반 시민은 집계 인구 모델입니다. 화면의 작은 주민은 시각적 표현이며 개별 생애 AI는 없습니다. 나라는 생산·소비·수용 인구·재산·기술·안정성·성향에 따라 성장합니다. 접경에서 관계가 생기고, 관계 악화와 성향·안정성이 전쟁을 결정합니다. 영토에 비해 행정 역량이 부족하면 안정성이 하락해 독립으로 이어질 수 있습니다. 역사에 기록하는 연도는 발생 시점이며, 연도에 따라 사건을 강제하는 일정표는 없습니다.

렌더러는 이 단계의 지도 규모에 맞춰 **PixiJS 대신 Canvas 2D**를 사용했습니다. 지형과 국경은 세계 스냅샷이 바뀔 때 래스터 캐시로 갱신하고, 카메라와 주민 효과만 매 프레임 처리합니다. GPU 스프라이트·청크 렌더링은 더 큰 지도와 아트 확장 시의 후속 과제입니다.

## GitHub 및 배포

[GitHub 저장소](https://github.com/vividhyeok/Ephocharium)

`vercel.json`에 Vite 설정을 준비했습니다. Vercel에서 이 저장소를 Import하면 연결된 운영 브랜치의 푸시마다 배포할 수 있습니다. 현재 원격 배포는 팀 접근 권한 오류(403)로 완료하지 못했으며, **확인된 Vercel 배포 주소는 없습니다.** GitHub Actions에는 빌드·엔진 테스트·브라우저 테스트를 실행하는 워크플로를 포함했습니다.

외부 폰트나 외부 게임 자산을 요청하지 않으며, 게임 계산과 저장은 브라우저 안에서 동작합니다. 최초 정적 파일을 내려받은 뒤의 게임 작동에는 게임 서버가 필요하지 않습니다. 오프라인 재접속을 위한 서비스 워커는 아직 없습니다.
