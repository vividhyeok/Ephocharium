# 0.6.1 — 식량·연구·외교 균형

- 경작지·기술·수자원·노동력에 따른 실제 생산량을 늘려 수용 인구 대비 만성적인 식량 부족을 줄였습니다. 무인 도시나 피해 지역의 생산 제약은 유지합니다.
- 교육 수준과 실제 누적 도착 화물이 연구 속도에 영향을 줍니다. 굶주림·불안정·기반 시설 부족 시 발전 제한은 유지합니다.
- 산업 이후 노동력·자본을 요구하는 수력 등 분산 전력을 추가하고, 국가 전력 누적을 도시별 반복 감쇠에서 연간 합산으로 수정했습니다.
- 자연 동맹은 국가당 직접 동맹 2~3개로 제한합니다. 기존 저장의 초과 동맹은 진행 중 정리되며, 약화된 동맹도 해체될 수 있습니다. 사용자의 수동 동맹은 즉시 제한하지 않고 다음 외교 재편 때 적용합니다.
- 공동 위협의 관계 보너스를 제한했습니다. 최신 원격 코드의 실제 약탈·해상 원정·조공·독립 기능을 보존하고, 접경 전쟁의 안정성 조건을 0.34에서 0.30으로 조정했습니다. 휴전 기간과 동시 전쟁 한도는 유지합니다.

검증: 통합 후 관련 단위 검사 47개와 TypeScript/프로덕션 빌드 통과. 크기 48, 세 시드(42/91/241026)의 각 2,000년 자연 실행 결과는 balance-0.6.1.json에 기록했습니다. 이 결과는 해당 시드·크기·기간의 관측이며 모든 국가의 발전이나 최대 지도 성능을 보장하지 않습니다. 이번 변경 후 18,000년 재실행은 수행하지 않았습니다.
