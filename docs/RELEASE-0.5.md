# Epocharium 0.5.0 작업 기록

0.5.0은 지형 수문·유한 광상·도시 창고·인구 코호트·실물 화물 운송·문화와 종교·그림 중심 국가 패널을 통합한 개발 버전입니다.

- 자체 SVG 오브젝트 67종과 시대/문화 스카이라인 70종, 내장 이미지 생성 도구로 제작한 계곡 원화 1점을 추가했습니다.
- 도구 기능과 그림을 대응시키고 선박 실루엣을 다시 그렸습니다. 확대 단계별 지도 정보, 터치 이동/핀치 확대, 모바일 가로·세로 HUD를 적용했습니다.
- 저장 이후 미래 재현, 자원 보존, 인구 위기, 수문, 전달 패치 등을 포함한 단위 검증 40개가 통과했습니다. 기존 브라우저 14개는 전체 실행 11개 및 수정 뒤 실패 항목 3개 재실행에서 통과했습니다. 신규 반응형/터치 검증도 통과했습니다.
- 프로덕션 빌드 성공. 3개 시드 18,000년 및 대형 세계 검증은 완료했으며 모든 측정 지점에서 저장 유효성을 통과했습니다. benchmark-0.5.json은 측정 원본입니다.
- Vercel GET /v10/projects: 403 forbidden. u-sukims-projects 팀 접근 권한이 없어 배포되지 않았습니다.

사용자 추가 요청에 따라 블러 제거·산맥 개선·동맹 색상·도시명·문명 레벨·간척과 해외 정착을 후속 변경으로 진행합니다. 현 커밋은 이 작업 전 0.5.0 체크포인트이며 완성된 최종 출시 인증을 뜻하지 않습니다.
