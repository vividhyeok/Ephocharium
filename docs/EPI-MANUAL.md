# 에피 실제 연동 수동 검증

자동 테스트는 실제 비용을 발생시키지 않습니다. 다음 항목은 실제 DeepSeek 계정과 키를 가진 운영자가 별도로 확인합니다.

1. `.env.example`을 `.env.local`로 복사해 DEEPSEEK_API_KEY, EPI_ACCESS_TOKEN(24자 이상 무작위), EPI_ENABLED=true를 설정합니다. 공급자 계정의 지출 제한을 먼저 확인하세요.
2. `npm run dev`를 한 번 실행하면 Vite와 에피 API가 같이 실행됩니다. `/api/epi` GET에서 enabled=true가 나오는지 확인합니다. 키 문자열 자체를 출력하거나 화면에 공유하지 마세요.
3. 에피의 접근 설정에 초대 코드를 입력합니다. '지금 가장 강한 국가가 어디야?'라고 묻고 게임 목록의 인구·레벨, 실제 배치 군대, 에피의 부문 순위를 대조합니다. 종합 순위 기준은 README의 상대 로그 평가입니다.
4. 실제 존재하는 국가 둘을 이름으로 비교합니다. 인덱스에 없는 '존재하지않는나라'를 물으면 만들어내지 않는지 확인합니다. 국가 링크가 지도와 국가 패널로 이어지는지 봅니다.
5. 국가를 선택해 발전 정체 이유를 묻고 국가 패널의 실제 정체 조건과 비교합니다. 지도자의 개인 성향과 국가 정책을 혼동하지 않는지 확인합니다.
6. 300년 전 비교를 묻습니다. 50년 간격 집계가 없으면 부족이라고 답해야 합니다. 오래된 전쟁은 보존 범위와 누적 통계를 구분해야 합니다.
7. 20배속 중 질문하고 답변의 관측 연도가 질문 시점으로 유지되는지 확인합니다. 중단 버튼, 패널 닫기, 다시 열기, 다른 세계 생성과 이전 세계 불러오기를 확인합니다.
8. 짧은 대화를 여러 번 이어가 봅니다. 서버 제한은 시간당 12개이므로 실제 20턴 검증은 시간을 나누어 진행합니다. 로컬 대화는 최근 20턴, 전송은 최근 8턴이며 이전 질문은 요약됩니다. 다른 세계의 대화가 섞이면 안 됩니다.
9. 키 누락·잘못된 키·잔액 부족·속도 제한은 해당 안내가 나와야 합니다. 중간 연결을 끊으면 일부 답변과 오류 표시가 남아야 하며 게임 재생은 계속됩니다. 자동으로 같은 유료 요청을 반복하지 않습니다.
10. 브라우저 Network의 요청은 `/api/epi`만 사용해야 하고 DeepSeek Authorization 키는 클라이언트 요청과 번들에 없어야 합니다. 실제 호출은 서버에서 api.deepseek.com/chat/completions로, 모델 deepseek-flash와 thinking disabled로 실행됩니다.
11. Vercel에서는 프로젝트 환경변수에 같은 설정을 등록한 뒤 재배포합니다. 공개 활성화 전 전역 인증·속도 제한/지출 상한을 별도로 마련하세요. 프로세스 메모리 제한만으로 전체 과금을 제한할 수 없습니다.

모킹으로 검증한 스트리밍·도구 호출 형식과 실제 공급자의 응답은 구분합니다. 모델이나 계정의 이용 가능성이 달라진 경우 공급자 공식 문서를 확인하세요.
