# Epocharium 0.5.1

## 지도와 관찰
- 배경 업스케일 블러를 제거하고 연결된 능선·암면·설봉으로 산맥을 표현합니다.
- 국가 이름은 짧은 이름과 문명 레벨만 표시합니다. 중복 인구 라벨을 없앴습니다.
- 도시명은 기본 숨김입니다. ‘표시’에서 켜면 3.5배 확대부터 표시하며, 국가 선택 중에는 해당 국가 도시만 표시합니다. 빈 도시는 숨깁니다.
- 마우스오버로 도시 인구·국가·시대·외교 요약을 확인합니다. 국가 선택/호버 시 직접 동맹은 청록색 연결선, 전쟁은 주홍색 점선으로 표시합니다. 깜빡임은 사용하지 않습니다.
- 동맹 연결망은 같은 영토 색을 사용하지만 개별 국경과 소유권은 유지합니다. 연결망의 모든 국가가 서로 직접 동맹이라는 뜻은 아니며 연결선은 실제 양자 관계만 표시합니다.
- 국가명, 도시명, 외교 연결은 ‘표시’에서 각각 끌 수 있습니다. 국가 정보에 동맹·적대 국가, 문명 레벨과 기술 순위를 표시합니다.

## 개척
- 산업 시대 해안 간척과 고대 이후 관개는 석재 12·목재 8·자금 60을 착공 시 지불합니다. 연간 유지 비용, 도시 피해에 따른 공사 중단, 점령 시 중단 처리가 있습니다.
- 간척 24년, 관개 12년 뒤 실제 토지와 비옥도가 바뀌며 사건 연표에 기록됩니다. 지도 바깥 네 면은 간척 대상에서 제외합니다.
- 중세 이후 항구에서 주민 24명과 실물 화물을 실은 개척선이 다른 육지의 무주지로 항해합니다. 도착해야 정착지가 생성되며 이미 점유된 곳이면 귀환합니다. 기존 국가를 강제로 식민지화하는 속국·착취 체계는 구현하지 않았습니다.

## 검증과 범위
- 단위 테스트 44개 통과, TypeScript 및 프로덕션 빌드 성공.
- 0.5.0 장기 검증: 세 시드 각각 18,000년, 256 크기 세계 3,000년 모두 저장 유효성 통과. 측정 원본은 benchmark-0.5.json. 이 결과는 후속 개척 기능 이전 버전의 기준 자료입니다.
- 새로운 개척 기능은 자원/주민 보존, 공사 진행·저장 복원, 점유 충돌, 해안 보호 단위 검증을 수행했습니다. 0.5.1의 18,000년 재검증은 하지 않았습니다.
- 인구는 코호트 모델이고 화면 주민은 대표 개체입니다. 장기 노령화·인구 붕괴 및 시대 퇴행이 가능한 개발용 균형이며 모든 하드웨어에서 일정 FPS를 보장하지 않습니다.
- Vercel 프로젝트 조회 403으로 배포하지 않았습니다. Git 푸시와 서비스 배포는 별개입니다.

## 미술 출처
도구/물체 SVG 67종과 문화·시대 스카이라인 70종은 저장소의 art.ts/toolArt.ts 및 generate-art.mjs로 제작했습니다. 선박·지형·산맥은 Canvas 코드 원화입니다. living-valley.png는 내장 이미지 생성 도구로 제작한 강·농지·항구·산업 도시 파노라마입니다. 외부 게임 스프라이트를 사용하지 않았습니다.

국가 목록은 전체 생존 국가를 대상으로 인구·기술·영토 정렬, 동맹망·대표 종교 그룹 열람, 이름 검색을 제공합니다. 그룹별 국가 수와 총인구, 국가별 문명 레벨·인구·상대 막대로 비교할 수 있습니다. 종교는 실제 주민별 신앙 통계가 아닌 국가 대표값입니다.
