# 개발 및 검증 현황

작성일: 2026-10-24 (한국 시간). 현재 버전 **0.5.1**. 최신 변경과 검증은 [0.5.1 기록](RELEASE-0.5.1.md)을 참고하세요. 아래 내용은 0.4 기준 기록입니다.

## 이번 변경의 범위

관찰 중심의 자율 문명 샌드박스를 유지하면서 시간·14개 시대·발전 성향·외교·사건·직접 개입·장기 기록을 연결했습니다. 이전의 지형·설원·국경·대표 주민 경로·자원 채취·정착지·군대 행군/공성/점령·동맹 방어 참전·항공 교역·저장 기능은 유지합니다.

### 실제 시간과 결정론

`src/time.ts`는 100ms 고정 처리 단위마다 1·2·5·10·20의 시간 크레딧을 쌓습니다. 40 크레딧마다 연간 계산 한 번을 실행합니다.

| 배속 | 실제 시간당 연간 계산 |
| ---- | --------------------- |
| 1×   | 4초에 1년             |
| 2×   | 2초에 1년             |
| 5×   | 초당 1.25년           |
| 10×  | 초당 2.5년            |
| 20×  | 초당 5년              |

인구·식량·재산·연구·행정·지도자 나이·주민 이동·자원 채취·군대·항공 모두 같은 연간 계산 안에 있습니다. 숫자 표시만 느리게 하지 않았습니다. 화면의 이동 보간 시간도 배속에 맞춥니다. 잔여 크레딧을 저장하고 일시정지할 때 UI에 동기화합니다. 백그라운드에서 지연된 실시간을 대량으로 따라잡지 않습니다. 같은 시드·같은 연도에 같은 개입을 하면 배속과 관계없이 같은 결과를 재현합니다.

진입에 필요한 재산은 다음 단계 번호×20입니다. 각 시대는 서로 다른 식량·소득·주거·이동 계수를 가지며 `src/eras.ts`에서 관리합니다. 도시의 외형은 해당 국가 시대와 실제 도시 개발도 중 낮은 단계로 그립니다. 국가만 새 시대로 바뀌어도 미개발 마을이 즉시 미래 도시가 되지는 않습니다. 인구·시설 투자에 따라 건축물 밀도와 높이도 달라집니다. 공항은 현대 이상, 충분한 도시 개발·인구·재산·공항 간 거리 조건을 요구합니다.

연구는 인구, 1인당 재산, 목재·금속 비축, 안정성, 우호 교류, 현재 연구 성향과 위성에 영향을 받습니다. 높은 기술에서는 비선형 비용이 증가합니다. 기근·심한 불안·전쟁에는 기술 손실과 시대 후퇴가 가능하고 회복하면 다시 연구합니다. 최종 시대 뒤에도 연구를 막지 않으며 주거 수용·도시 개발 상한, 전력, 산업·통신망, 위성·탐사 사업 한도가 기술에 따라 달라집니다.

### 자율 성향과 외교

- 농업·상업·산업·연구·군사 성향은 지형 생산성, 광물, 재산, 안정성, 전쟁과 교류를 보고 조금씩 이동합니다. 고정 클래스가 아닙니다. 식량·소득·금속 생산·연구·전투 효율에 반영되며 국가 패널에는 가장 강한 두 방향만 기본 표시합니다.
- 접경과 지역 교류, 식량·금속 압박, 세력·기술 격차, 팽창 성향, 공동 위협을 평가합니다. 전쟁의 원한은 관계에 남아 천천히 줄고 동맹은 교류·방어 관계를 유지합니다.
- 팽창하는 강국을 공동 위협으로 느끼는 국가들은 방어 동맹을 만들 수 있습니다. 동맹국의 실제 접경이 있을 때만 기존 군대 시스템으로 방어 참전합니다. 땅을 건너뛰는 점령은 없습니다.
- 휴전 뒤 회복 기간과 보급·불안에 따른 전쟁 종료 조건을 둡니다. 사건을 발생시키기 위한 고정 역사 스크립트는 없습니다. 떨어진 대형 세계에서는 오랜 평화와 발전이 가능하며 접경이 없으면 지상군을 만들지 않습니다.
- 무한 분열을 줄이기 위해 주거·생산 수용량을 함께 인구 성장에 반영하고, 독립은 지역 규모·인구·불안과 이전 분열 이후 회복 기간을 요구합니다. 독립국은 모국 기술의 일부를 이어받습니다.

### 사건과 역사

건국·멸망·전쟁·독립·시대 이행은 주요 사건으로 분류합니다. 지도자 교체·정치 변화·도시 발전·조약 등은 일반 사건입니다. 알림을 누르면 해당 위치로 이동합니다. 역사에서 주요 1개 / 최근 3개 / 숨김을 고르고, 자동 카메라를 별도로 켤 수 있습니다. 자동 카메라는 관찰 모드의 새 주요 사건에만 반응하고 실제 시간 최소 12초 간격을 둡니다.

시대별 첫 관측·경험한 국가·현재 분포, 200년 단위 사건 요약, 국가별 시대 이행, 연간 국가 집계 기준 최대 영토·영토 전성기, 오래 이어진/새 국가, 최근 100년 영토 변화를 제공합니다. 영토 표본은 최근 150개, 시대 이행은 국가당 최근 100개, 세부 역사는 최근 1,200개, 외교 기록은 최근 800개를 유지합니다. 요약은 최근 120구간(24,000년)을 보관합니다.

100년마다 영토를 RLE 압축해 최근 8회 보관합니다. 역사에서 선택한 시점과 현재의 소유국이 달라진 땅을 강조합니다. 과거 지형 전체를 되돌리거나 과거를 재생하는 기능은 아닙니다. 이전 저장에 없는 과거 영토와 알려지지 않은 조약 원인은 만들어 채우지 않습니다.

### 개입·복원·호환

- 전쟁·동맹·평화는 대상과 상대를 지도 또는 목록에서 직접 지정하고 실행할 수 있습니다. 지도 선택은 드래그로 여러 국가를 연속 지정하지 않도록 클릭당 한 번으로 처리합니다. 국가 표지 ①·②로 선택을 확인합니다.
- 접경 없는 전쟁에는 현재 지상 전선이 없음을 알려 줍니다. 빠른 자동 상대 선택과 대상 국가의 모든 전쟁을 끝내는 빠른 평화도 유지합니다.
- 지형·재해 브러시가 적용될 정확한 타일을 미리 칠해 보여 줍니다. 드래그 한 번 전 상태를 한 번만 복사해 실행 취소합니다. 실행 취소는 세계 전체를 개입 직전으로 되돌리므로 그 뒤 흐른 시간도 돌아갑니다. 재생성·불러오기에는 이전 취소 상태를 넘기지 않습니다.
- 기존 버전 1 저장을 허용하고 `progressRevision: 4`로 발전 척도를 한 번만 이전합니다. 구 항공 단계는 정보 단계, 그 이상 누적 기술은 로그 척도로 이어집니다. 연도·인구·난수 상태·원래 사건 날짜는 보존합니다. 이후 미래는 새 규칙에 따라 달라집니다.
- 이전 저장에 남아 있는 사건에는 실제 날짜로 중요도·요약을 붙입니다. 시점을 알 수 없는 과거 전성기·시대 이행은 소급해서 지어내지 않습니다. 0.3의 국가명·바다 여백 이전도 유지합니다.

## 실제 검증

Windows, Node.js 24.11.0, Playwright Chromium. 엔진 검증 31개·브라우저 검증 14개를 모두 통과했고 `npm run build`도 성공했습니다.

- 동일 시드의 성장·재해·독립·행군·전투·휴전·동맹 방어·항공·저장 이후 미래 재현 등 기존 검증.
- 14단계의 기준과 실효 계수, 위기 중 연구 쇠퇴와 회복, 조건에 따른 성향 이동.
- 1×와 20×에서 같은 시뮬레이션 기간을 처리한 전체 상태의 완전 일치.
- 최종 시대 조건에서도 자원 소비·산업·통신·위성·탐사와 연구·도시 개발의 추가 변화.
- 구 항공 문명의 1회 이전, 날짜·인구·난수 보존, 손상된 신규 기록·지도 거부.
- 두 국가 지정, 접경 부재 안내, 드래그 한 번 전 세계 파일과 실행 취소 후 파일의 완전 일치.
- 실제 브라우저 20× 진행량, 사건 표시량, 구버전 불러오기와 요약, 14개 서로 다른 실제 렌더러 결과 및 게임 화면·미래 도시 표시.
- 데스크톱·모바일 UI, 줌·미니맵·키보드 포커스·자동 저장·세계 파일 입출력.

대형 256×166 지도는 시드 91에서 1,000년 **10.88초**, 평균 **10.88ms/년**, 표시 주민 집단 440개, 저장 약 **4.68MiB**, 데이터 검증 통과였습니다. 시작 국가가 멀어 이 조건의 1,000년 시점에는 전쟁·동맹이 없었습니다. 다른 지도·기간에 대한 보장은 아닙니다.

측정 중 개발 서버와 일부 검증 작업도 실행했으므로 계산 시간은 이 PC의 관측치입니다. 국가 수와 전선이 늘면 경로·외교 비용도 증가합니다. 장기 원자료의 보존 외교 기록 수는 최근 800개 중 집계이며 전체 누적 전쟁 횟수로 해석하면 안 됩니다.

확대된 250년 세계의 최종 브라우저 120프레임 측정은 평균 **16.91ms**, 95백분위 **16.8ms**였습니다. 별도의 검증과 병행한 초기 측정에서는 평균 20–22ms도 관측했으며, 이 수치는 저사양 기기 보장이 아닙니다.

프로덕션 빌드: 메인 JS 약 **310KB / gzip 102KB**, Worker 약 **46KB**, CSS 약 **32.5KB / gzip 7.9KB**.

### 성능 처리

Worker는 시간이 실제로 1년 진행하거나 개입·불러오기·복원할 때만 전체 세계를 전송합니다. 배속·일시정지 조작은 전체 복사를 반복하지 않습니다. 이전보다 최대 배속의 연간 처리·스냅샷 빈도가 40회/초에서 5회/초로 줄었습니다. 일시정지의 잔여 시간 동기화는 작은 메시지로 처리합니다.

정적 지도는 `renderRevision`과 세계 교체 식별자로 캐시합니다. 단순 UI·시간 메타데이터 갱신에는 다시 만들지 않습니다. 확대 화면 밖 주민·부대는 픽셀 그리기를 생략합니다. 외교 관계를 Map으로 조회하고 공동 전선을 국가 쌍 집합으로 한 번 계산해 반복적인 지도 탐색을 줄였습니다. 실행 취소 복사도 타일마다 하지 않습니다.

전체 상태의 매년 전송과 타일 전체의 연간 캐시 갱신은 남아 있습니다. 완전한 타일 델타·청크 렌더링·공간 인덱스·GPU 전환까지 구현한 것은 아닙니다.

## 모델의 한계와 후속 작업

- 전체 인구는 집계하며 화면의 주민은 직업과 경로를 가진 대표 집단입니다. 세계 목표 약 900개, 국가당 최대 110개, 절대 상한 1,800개입니다. 개별 생애·가족·유전·주민 전원의 AI는 없습니다.
- 도시 인구는 국가에서 분배하며 독립적인 도시 경제·이주 시뮬레이션은 아닙니다. 금속 가공·회수와 산업·전력·통신은 집계 모델이며 세부 물질 수지·전력망 경로·건설 생산 사슬은 없습니다.
- 14단계와 연속 기술치이며 발명별로 분기하는 연구 트리는 없습니다. 정치 체제·권력은 간단한 안정성 모델이고 실제 선거·의회·왕조 계승 분쟁은 없습니다.
- 위성·탐사는 자원·연구·소득에 연결된 사업입니다. 우주 지도·궤도 역학·행성 식민지 경제와 개별 우주선 이동은 없습니다. 별도의 외부 AI를 호출하지 않습니다.
- 군대는 집단 단위입니다. 개별 총기 재고·탄도·충돌·전술 지휘·함대·해전·공중전은 없습니다. 항공은 국내 교역입니다. 국제 교류는 관계 단위 경제 효과이며 해상 교역선 경로를 계산하지 않습니다.
- 역사는 보관 한도가 있고 전체 연대 재생은 없습니다. 실행 취소는 마지막 개입 한 단계만 지원합니다.
- 저사양·실제 모바일 장기 성능, 256 지도 전체의 18,000년 실행, 자동화·우주·행성간 자연 도달 시점의 다수 시드 측정은 추가 검증 대상입니다.
- 터치 핀치 줌, 음향, 생태계·동물, 계절·기후, 추가 재해, 오프라인 서비스 워커는 후속 작업입니다.
