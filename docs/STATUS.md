# 개발 및 검증 현황

작성일: 2026-10-24 (한국 시간). 현재 버전 **0.3.0**.

## 0.3: 지형·국경·외교 맥락

- 북쪽의 일자 설원 띠를 불규칙한 설원과 북부 고지대 눈으로 변경했습니다. 눈 지형은 유지됩니다. 해안의 고도를 낮추고 바깥 두 줄을 바다로 보장하며 192·256 크기를 추가했습니다.
- 이전 세계는 한 번만 바다 여백을 덧붙이고 수도·정착지·주민·군대·경로·역사·효과·정착 좌표를 함께 옮깁니다. 인구·난수·연도는 유지됩니다.
- 가까이 보면 20×26 논리 픽셀 인물의 얼굴·모자·복장·작업 도구가 보입니다. 군대의 장비는 창·방패 → 검·방패 → 머스킷 → 소총으로 달라집니다. 도구 외형은 직업과 시대를 표현하며 개별 무기 재고 모델은 없습니다.
- 영토 색을 강화하고 국경에 어두운 바깥 윤곽을 추가했습니다. 지도 국가 표지에는 전쟁·동맹 기호도 표시합니다.
- 독립 국가의 이름을 반복 왕조 번호로 만들던 방식을 제거했습니다. 실제 반란·독립에서만 출신 국가를 기록합니다.
- 동맹은 별도 조약 상태이며 자원 지원·기술 교류와 실제 접경이 있는 국가의 방어 참전에 연결됩니다. 전쟁·휴전·동맹·해체의 발생 연도와 원인을 저장합니다. 기존 전쟁의 알려지지 않은 원인은 추정해서 채우지 않습니다.
- 상단 외교 표시는 hover/focus로 요약을 읽고, 역사 패널의 외교 관측실에서 관계별 상세 기록과 연표를 확인합니다.

## 0.2에서 추가한 실제로 움직이는 문명

이전의 제자리 왕복 주민 표현을 제거했습니다. 이제 표시 주민 집단은 고유 ID, 직업, 집, 목적지, 경로, 작업/휴식 상태와 좌표를 저장합니다. 프레임마다 가짜 위치를 만드는 대신 저장된 이전·현재 좌표를 보간해서 그립니다.

- **인구와 주민:** 실제 집계 인구에 비례해 표시 집단이 추가·제거됩니다. 농부, 벌목꾼, 광부, 건축가, 상인, 주민, 지도자가 서로 다른 일을 합니다. 경로 탐색은 바다·산과 타국 영토를 피합니다.
- **자원:** 숲에는 목재량, 광맥에는 유한한 광물 매장량이 있습니다. 작업장에서 벌목·채굴하면 자원이 줄고 국가 비축이 늘어납니다. 고갈된 숲은 그루터기로 보이고 천천히 재생됩니다. 건설과 유지에는 목재·금속이 필요합니다. 자원 도구는 실제 광물 매장량을 늘립니다.
- **정착지와 건설:** 국가에 정착지 객체가 생깁니다. 인구·자원·재산·가용 공간이 충분하면 새 마을이 생기고 주거 구조물이 증가합니다. 자원이 부족하면 건설이 늦어지고 주거 부족은 안정성에 영향을 줍니다. 높은 기술은 더 많은 인구를 수용합니다.
- **시대 변화:** 기술, 재산, 인구, 식량과 자원이 연구 속도에 영향을 줍니다. 부족 → 농경 → 왕국 → 산업 → 현대 → 항공의 여섯 단계입니다. 특정 연도가 되면 강제로 발전시키지 않습니다. 신규 정착지는 개발에 시간이 필요합니다.
- **시각적 발전:** 천막·모닥불, 농장·마을, 성곽, 공장·굴뚝, 고층 건물·포장도로, 공항으로 달라집니다. 상인의 이동이 도로를 만들고 산업 시대 이후 상인은 차량으로 표현됩니다.
- **전쟁:** 전쟁 중 실제 부대가 정착지에서 출발해 행군하고 적 영토에서 전투·공성을 합니다. 기술, 병력, 지도자 권위, 수도와의 보급 거리, 숲의 방어 효과와 상대 부대가 결과에 영향을 줍니다. 전투가 인구·식량·재산·지형 피해와 점령을 일으킵니다. 이전의 무작위 즉시 타일 점령 코드는 제거했습니다. 평화 능력은 즉시 부대를 해산합니다.
- **권력:** 지도자는 이름·나이·성향과 지도 위 왕관 표지를 가집니다. 부족 의회·군주정·공화정·권력 공백을 구분하고 권위가 전투 효율에 반영됩니다. 권력 공백에는 지도자 표지가 사라집니다.
- **비행기:** 항공 기술, 유지비, 개발된 공항 두 곳 이상을 갖추면 국내 항공 교역이 생깁니다. 비행은 출발·도착 공항, 진행률, 화물을 저장하며 도착하면 실제 교역 수입이 생깁니다. 공항은 가까운 곳에 중복 건설하지 않고 국가당 최대 세 곳입니다.
- **정보와 조작:** 국가 패널에서 시대, 다음 시대 진척, 정착지 수, 정치 체제, 권위, 비축 자원과 부대·항공기 수를 확인합니다. ‘도시 가까이 보기’와 ‘전선 가까이 보기’를 제공합니다. 지도에 커서를 올리면 지형·목재·광물과 그곳 주민의 직업·활동을 확인합니다.
- **저장 호환:** 기존 버전 1 세계는 국가·인구·역사·난수 상태를 유지하면서 추가 상태를 초기화합니다. 새 저장에는 주민 경로, 정착지, 정치 상태, 부대, 항공기까지 포함합니다. 이미 새 상태가 있는 세계는 불러올 때 재생성하지 않습니다.

### 표시 단위와 모델의 한계

전체 인구는 집계 모델입니다. 화면의 주민 하나는 실제 한 사람 전원의 생애 AI가 아니라 **직업을 가진 대표 집단**입니다. 국가당 표시 상한은 110개 집단이며 세계 전체 목표는 약 900개, 절대 상한은 1,800개입니다. 실제 표시 인구 비율은 왼쪽 세계 상태에 표시합니다.

정착지 인구는 국가 인구를 나눠 계산하며 독립적인 도시별 출생·이주 경제는 아직 없습니다. 집과 고층 건물은 주거 구조물의 대표 표현입니다. 일반 시민 개개인의 나이·가족·유전·개별 사망 일대기, 정교한 건설 대기열은 없습니다.

시대는 공통 기술치에 따른 여섯 단계 분류입니다. 개별 발명이나 여러 갈래의 연구 트리는 없습니다. 정치 체제도 안정성과 기술·성향에 근거한 간단한 모델이며, 실제 선거·의회·귀족 가문·왕위 계승 분쟁은 없습니다. 군대는 병력 집단 단위이며 개별 탄도·충돌 물리·전술 지휘·해전은 없습니다. 항공은 국내 도시 간 교역 모델이며 개별 승객, 국제 항공, 공중전은 없습니다.

## 실제 검증

환경: Windows, Node.js 24.11.0, Playwright Chromium. 데스크톱 1440×1000, 모바일 390×844.

### 엔진: Vitest 24개

기존 명세 A–H: 20명 정착, 네 왕국의 650년 변화, 인구·자원 지원의 영향, 제국의 행정 부담·독립, 재해 피해·회복, 시드별 재현·차이, 2,000년 장기 실행, 저장·복원 후 미래 일치. 추가로 여섯 프리셋, 바다 정착 거부, 손상 파일 거부를 검사합니다.

0.2에서 추가한 8개 검증:

1. 주민의 실제 좌표 변화, 자국 땅 안에서의 이동, 인구 지원에 따른 표시 집단 증가.
2. 바다·산·타국 영토를 피하는 경로 탐색.
3. 벌목·채굴에 따른 현장 자원 감소와 비축량 변화(대조 세계 비교).
4. 연도와 분리된 시대 판정, 정착지 발전·공항·항공로 및 비행 진행률 연결.
5. 행군 후 전투·점령·피해, 평화 후 부대 해산.
6. 불안정한 국가의 권력 공백과 지도자 표지 제거.
7. 구버전 세계 초기화 시 기존 인구·역사·RNG 보존.
8. 경로·항공·정치 상태를 포함한 저장·복원 이후 미래 일치와 잘못된 경로 거부.

0.3 검증 5개: 대형 지도 네 면 바다·설원 보존, 구버전 바다 여백과 경로 이전·중복 이전 방지, 국가명 2,000개 중복 방지, 조약의 원인·연도·실제 교류, 실재하는 접경이 있을 때만 방어 참전.

### 브라우저: Playwright 9개

- 세계 생성·배속·일시정지·저장 슬롯·다운로드·불러오기·관찰 모드.
- 모바일 레이아웃과 재해 도구, 가로 넘침 없음.
- 잘못된 파일 거부와 기존 지도 유지.
- 왕국 목록·미니맵·줌 및 패널 키보드 탐색.
- 자동 저장 후 새로고침 복원.
- 250년 세계에서 지도 선택과 인구 지원.
- 항공 시대 세계를 도시 단위로 확대한 뒤 실제 내보낸 저장 파일에서 주민 좌표와 항공 진행률 변화 확인.
- 전선 확대, 군대 확인, 평화 능력 사용 후 전쟁·부대가 즉시 사라짐.
- 외교 현황의 hover·키보드 focus 요약, 조약 원인 표시, 실제 연표 열람.

고급 문명·접경 전투 브라우저 검증에는 초기 조건을 명시한 테스트 세계를 사용했습니다. 일반 세계의 자연 발전과 장기 상태는 엔진 테스트 및 별도 장기 실행으로 확인했습니다. 테스트 성공이 여러 시간 동안의 재미나 모든 기기 성능을 증명하지는 않습니다.

### 성능과 배포

- 250년 세계를 확대한 브라우저의 120프레임: 평균 약 **16.45ms**, 95백분위 **16.7ms**. 이 PC에서의 짧은 측정이며 저사양·실제 휴대전화 성능 보장은 아닙니다.
- 0.3 프로덕션 빌드: 메인 JS 약 **296KB / gzip 97KB**, Worker 약 **34KB**, CSS 약 **30KB / gzip 7.4KB**.

- 장기 실행의 최종 수치는 `성능 측정` 항목에 기록합니다. 초기 0.1의 집계 엔진만으로 측정한 2.6초와 비교해 현재의 경로·주민·군대 모델은 계산량이 늘었습니다.
- `npm audit`: 취약점 0개.
- GitHub: https://github.com/vividhyeok/Ephocharium
- Vercel 설정은 준비했지만, 연결된 팀 접근 권한 요청이 403으로 거부되어 원격 배포는 완료하지 못했습니다. 확인된 Vercel 운영 주소는 없습니다.
