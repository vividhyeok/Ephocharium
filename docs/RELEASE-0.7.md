# 0.7.0 — 관찰자의 세계

- 새 설치와 기본 새 세계는 여러 비옥한 유역의 정착 집단으로 시작합니다. 재생은 기본 5배속이며, 국가는 정착 과정에서 스스로 생깁니다. 다른 프리셋과 지형·속도 세부 설정은 선택 사항입니다.
- 성장한 국가의 정착민이 실제 인구와 비축 식량을 가지고 이동합니다. 지형·통행 가능 여부·농지·기존 수도와의 거리를 기준으로 이동할 땅을 고릅니다. 도착한 집단은 모국 계보가 남는 독립 국가를 세울 수 있습니다.
- 농업, 교역, 연구, 산업, 군사 우선순위는 식량·부양 압력·전쟁·재정에서 결정됩니다. 정책에는 투자비가 들며 생산·운송·연구가 달라집니다. 결정과 근거는 국가 패널에서 확인합니다.
- 국경이 떨어진 상대라도 도달 가능한 육상 경로나 항구·연결된 해역이 있으면 전쟁할 수 있습니다. 중립국의 군사 통행 허가에는 기한이 있고, 강제 진입은 별도 전쟁으로 기록됩니다. 배와 군대는 지도에서 이동하며 식량·자재·인력을 사용합니다. 해상 보급은 항구와 항로가 필요합니다.
- 기본 관찰 화면에는 연표, 국가 정보, 사건 따라가기가 있습니다. 지형 편집, 재해, 강제 외교, 되돌리기는 사용자가 실험 모드로 바꿨을 때만 작동합니다.

정책 결정은 현재 세계 상태에 기반한 게임 엔진 규칙입니다. 외부 모델 통치나 자유 형식 개헌은 이번 버전에 포함되지 않습니다. 기존 저장에 새 필드를 요구하지 않으며, 새 규칙은 해당 세계가 진행될 때 적용됩니다. 처음부터 정착 과정을 보려면 새 세계에서 기본 설정으로 시작하세요.

지도 크기 80의 시드 42·91·241026을 개입 없이 240년씩 실행했습니다. 각 세계는 초기 정착 집단 5곳에서 시작해 독립 건국 15~20건, 개전 17~21건, 약탈 1~2건, 영유 구역 829~1,070칸에 도달했습니다. 세 세계 모두 저장 형식 검증을 통과했습니다. 숫자는 이 세 실행의 관측값입니다.
