# EPOCHARIUM 0.6.0

- 에피: 실제 세계 스냅샷과 읽기 전용 조회 도구를 사용하는 스트리밍 기록관. 국가 링크, 대화 보존, 중단·재시도, 모바일 지원.
- 서버 전용 DeepSeek 키, 명시적 활성화와 접근 코드, 요청 크기·횟수 제한. 공개 AI는 기본 비활성화이며 제한은 인스턴스 단위입니다.
- 지도자 성향과 국가 정책 분리, 장기 전쟁·동맹·지도자 기록과 50년 단위 국력 기록.
- 노동력·주거에 따른 인구 변화, 유지 인력 부족 시 도시 쇠퇴·폐허·기술 퇴보, 이주·물자 유입을 통한 회복.
- 저장 모달 겹침, 국가 목록 접근성 이름, 스트리밍 저장 비용 개선.

## 검증 및 한계

타입 검사와 프로덕션 빌드 통과. 에피/API 회귀 검사 13개 통과(모의 공급자 사용). 실제 유료 DeepSeek 응답은 키 설정 후 확인이 필요합니다.

18,000년 시뮬레이션의 최종 인구는 시드 42: 46,195명, 91: 36,327명, 241026: 40,623명입니다. 세 번째 실행의 마지막 저장 검증은 실패했으며, 누적 국가 기록의 256개 제한을 실제 국가 수에 맞추는 수정 및 300개 국가 회귀 검사를 추가했습니다. 전체 18,000년 재실행은 미완료입니다. 원본 측정 결과를 benchmark-0.6.json에 보존했습니다. 최대 크기 지도 3,000년 실행은 앞선 검증 실패로 실행되지 않았습니다.

동일한 대형 지도 스냅샷의 200년 처리 비교는 구버전 59.11ms/년, 새 버전 70.59ms/년(1.19배)이었습니다. 동시 작업이 있는 환경의 측정으로 절대 성능 보장은 아닙니다. 상세 결과는 performance-0.6.json을 참고하세요.

최근 지도자 상세 기록은 국가별 80명, 국력 기록은 400개, 로컬 대화는 20턴으로 제한합니다. 서버 전송은 최근 최대 8턴이며 큰 요청은 6턴으로 축소합니다. 오래된 미수집 사실은 추측하지 않습니다.

설정 및 실행은 README.md와 EPI-MANUAL.md를 참고하세요.
